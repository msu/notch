# Code Actions

```
if-statements:
- remove dangling else
  - remove empty else
- add else clause
  - add & navigate to it
- invert if-statement
  - add a not condition (paren aware)
  - flip the true & false blocks

repeat statememts:
- convert between index-based & iterable based

logical statements (and/or/not):
- apply de morgan's law
  - flip (!a && !b) -> !(a || b)

identifier expression:
- add is [not] empty/is [not] null/is [not] undefined
```
