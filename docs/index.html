Notch

{{ site.tagline }}

Notch is a powerful and customizable scripting and programming language. It was built for use with the Sunny templating engine but is not at all coupled with it.

It is intended to be used with the Java ecosystem and has sane integrations with JVM types.

Design goals

  • seamless JVM-type integration
  • simplicity for ease of reading and writing
  • sane null propagation and defined semantics for weird type interactions
  • outstanding developer experience
  • syntax extensibility

Install

Notch is a Maven project. Clone the repository and build with Maven:

git clone https://github.com/msu/notch.git
cd notch
mvn package

Then run the REPL:

java -jar target/notch-1.0-SNAPSHOT.jar

Documentation

  • Syntax - primary expressions, operators, statements, closures.
  • JVM integration - calling Java methods, type coercions.
  • REPL - interactive shell, history, meta-commands.
  • Chisel - the language-agnostic foundation Notch is built on.
  • Templates - the built-in template engine for rendering text with embedded Notch expressions.
  • JSON5 - JSON5 parser and a small query language.
