Notch — a scripting and programming language for the JVM, from Montana State University (MSU)

Scripting
For Java & Minecraft

Notch is a scripting and programming language for the JVM, built at Montana State University. It runs anywhere Java runs, calls directly into Java libraries, and stays small enough to learn in an afternoon.

Speaks Java, natively
{% highlight notch %} import java.time.LocalDate today = LocalDate.now() for name in ['Alice', 'Bob', 'Carol'] print('Hello, ' + name + '! Today is ' + today) end {% endhighlight %}
Null that won't surprise you
{% highlight notch %} name = null greeting = name ?: 'anonymous' print(greeting) setting = config? ?: 'default' print(setting) {% endhighlight %}
Reads like you'd say it
{% highlight notch %} print('notch' starts with 'no') print('notch' contains 'otc') print([1, 2] is not empty) lengths = ['a', 'ab', 'abc'].map(\ s -> s.length) print(lengths) {% endhighlight %}
Objects when you want them
{% highlight notch %} class Greeter field name function hello() return 'Hi, ' + this.name end end g = new Greeter() g.name = 'Ada' print(g.hello()) {% endhighlight %}
