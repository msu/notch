# Notch

Notch is a powerful & customizable scripting & programming language. It was built for use with the Sunny templating 
engine but is not at all coupled with it.

It is intended to be used with the Java ecosystem & has sane integrations with JVM types. 

## Design Goals
- seamless JVM-type integration
- simplicity for ease of reading & writing
- sane `null` propagation & defined semantics for weird type interactions
- outstanding developer experience
- syntax extensibility
